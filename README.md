# Hospitality-Analytics-Dashboard

This project presents a Power BI dashboard that provides revenue and performance insights for the hospitality sector. It is designed to help hotel management teams, analysts, and decision-makers understand how different properties, cities, and booking platforms are performing based on key metrics.

## Project Overview

The dashboard enables deep analysis of core performance indicators in the hotel business such as:

- Revenue
- RevPAR (Revenue Per Available Room)
- Occupancy Percentage
- ADR (Average Daily Rate)
- Realisation Percentage
- Cancellation Percentage
- Average Rating

It also allows users to filter and analyze data based on:

- City
- Room Class
- Room Category (Luxury or Business)
- Booking Platform
- Day Type (Weekday vs Weekend)
- Weekly Time Periods

## Dashboard Explanation

- The dashboard brings together data from multiple hotel properties to provide a centralized performance overview.
- Users can monitor week-over-week changes in KPIs like revenue, RevPAR, ADR, and occupancy percentage.
- Filters allow slicing the data by city, room class, and room category to compare specific segments.
- The visuals are interactive, helping users explore trends, deep-dive into platform performance, and assess property-level metrics.
- A weekly trend chart shows how RevPAR, ADR, and occupancy percentage are changing over time, helping identify patterns or shifts.
- A detailed table displays individual property performance across all key metrics including bookings, ratings, and cancellations.

## Key Features

- Interactive filters for city, room class, and category
- Weekly trend line charts for RevPAR, ADR, and occupancy percentage
- Revenue breakdown by luxury and business categories
- Platform-wise comparison of ADR and realisation percentage
- Comparison of weekend and weekday performance
- Summary table of all hotel properties with individual KPIs
- Performance tracking using real-time metrics and week-over-week comparisons

## Files Included

- `Revenue Insights in Hospitality Domain.pbix` – This is the Power BI file containing the interactive dashboard
- `Revenue Insights in Hospitality Domain.pdf` – A PDF version of the report for quick reference or sharing

## Tools Used

- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query Editor
- Data Modeling with relationships and calculated columns

## How to Use

1. Open the `.pbix` file using Power BI Desktop.
2. Use the filters at the top of the dashboard to select the city, room class, or category you want to analyze.
3. Review the summary metrics and trend visualizations.
4. Explore the booking platform breakdown and compare individual property performance.
5. Use the insights for decision-making, operational improvements, or stakeholder reporting.

## Purpose

This project simulates a real-world hotel analytics scenario where business users need to evaluate operational efficiency, optimize pricing strategies, and improve customer satisfaction based on actual performance data.
